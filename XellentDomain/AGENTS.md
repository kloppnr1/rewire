# Domain documentation

Read [workspace instructions](../AGENTS.md) for safety, verification, branch,
and package publication rules, including when this repo is the session root.

For Xellent data, utility business relationships, or Xellent → Settl mapping
questions, start at [docs/ai/start.md](docs/ai/start.md). Read the topic needed
for the question, then follow individual evidence links when necessary.

Use the same entry point for delegated domain investigations. Give each agent a
bounded business question and require evidence, unresolved assumptions, and
dependencies in its response. The entry point does not authorize additional
agents, database access, or writes. Workspace instructions still apply.

For code or public API changes, use the [development guide](docs/ai/development.md)
for ownership, consumer impact, source mapping, and local verification.
